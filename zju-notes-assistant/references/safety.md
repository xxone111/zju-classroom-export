# Safety

## Access

- Only export replays the user can access after normal login.
- Do not bypass access controls, paywalls, DRM, or browser security interstitials.
- Do not scrape or download content from accounts the user cannot normally access.

## File Modification

- Downloads are allowed.
- Copy transcript exports into course-note folders when configured and confirmed.
- Before modifying a PDF, use the matching policy in `matching.md` and report the chosen path.
- Do not create PDF backups by default unless the user asks or the operation/tool requires it for safety.
- When updating existing notes, preserve user-written content and local style.

## Deletion and Cleanup

- Never permanently delete raw transcripts, DOCX exports, Markdown exports, PDFs, or notes.
- Cleanup must move files to macOS Trash/废纸篓 or another clearly recoverable trash location.
- Do not use `rm`, `unlink`, direct filesystem removal, or equivalent irreversible deletion for cleanup.
- If moving to Trash fails, leave the file in place and report that cleanup was skipped.
- Do not delete courseware PDFs or existing chapter notes.

## Verification

- Confirm exported transcript files contain expected content before organizing or cleaning up.
- Confirm generated notes are in the intended course folder.
- Confirm PDF annotations appear on intended pages when annotation is requested.
- Confirm course homepage `#Content` links are not duplicated and `*with record*` is added only where lecture content exists.
